# Movie Ticket Booking System
## Project Overview
### The Movie Ticket Booking System is a console-based Java application developed as part of a Data Structures and Algorithms (DSA) project. It manages movie hall seating, ticket bookings, cancellations, confirmed bookings, and customer waiting lists.
The cinema hall consists of 5 rows (A–E) with 5 seats per row, providing a total capacity of 25 seats.
