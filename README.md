# Movie Ticket Booking System

## Project Overview
### The Movie Ticket Booking System is a console-based Java application developed as part of a Data Structures and Algorithms (DSA) project. It manages movie hall seating, ticket bookings, cancellations, confirmed bookings, and customer waiting lists.The cinema hall consists of 5 rows (A–E) with 5 seats per row, providing a total capacity of 25 seats.

## Features
- Display the cinema hall seating arrangement.
- Book available seats.
- Generate unique booking IDs starting from T101.
- Prevent duplicate seat bookings.
- Cancel confirmed bookings.
- Manage a waiting list when the hall is full.
- Give Gold customers priority over Regular customers.
- Automatically allocate cancelled seats to the highest-priority waiting customer.
- Search bookings using booking IDs.
- Display confirmed bookings in sorted order.
- Save and load bookings using file handling.
